## Какие навыки демонстрируют запросы
- Агрегация данных (`COUNT`, `SUM`, `AVG`)
- Группировка (`GROUP BY`)
- Объединение таблиц (`JOIN`, `LEFT JOIN`)
- Оконные функции (`OVER`, `LAG`)
- Обобщенные табличные выражения (`CTE`)
- Фильтрация и сортировка (`WHERE`, `ORDER BY`, `LIMIT`)
